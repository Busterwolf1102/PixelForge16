# PixelForge 16 한국어 튜토리얼

이 튜토리얼은 처음 실행한 뒤 5분 안에 큐브를 고치고, 면을 밀어내고,
색을 바꾸고, 저장하는 흐름을 기준으로 작성했습니다.

## 1. 실행하기

배포 폴더에서 실행합니다.

```text
dist\PixelForge16\PixelForge16.exe
```

처음 화면에는 기본 큐브와 네 개의 뷰가 보입니다.

```text
TOP           위에서 본 화면
PERSPECTIVE   자유 회전 화면
FRONT         앞에서 본 화면
SIDE          옆에서 본 화면
```

화면 아래에는 현재 렌더 모드, 스냅, 그리드, 정점 수, 면 수, 현재 색,
16색 팔레트가 표시됩니다.

## 2. 뷰 조작

마우스를 원하는 뷰 위에 올린 뒤 `SPACE`를 누르면 그 뷰가 전체 화면처럼
확대됩니다. 다시 `SPACE`를 누르면 4분할 뷰로 돌아옵니다.

Perspective 뷰에서는 다음처럼 카메라를 움직입니다.

```text
마우스 가운데 버튼 드래그        회전
Shift + 가운데 버튼 드래그       이동
마우스 휠                       확대 / 축소
Home                            전체 모델 보기
Ctrl + Home                     모든 뷰 초기화
```

## 3. 정점 직접 움직이기

정점 위에 마우스를 올리면 작은 점이 강조됩니다.

```text
왼쪽 클릭 + 드래그
```

이렇게 바로 정점을 움직입니다. 별도의 Move Tool을 고를 필요가 없습니다.

뷰마다 움직이는 축이 다릅니다.

```text
TOP       X / Z 이동
FRONT     X / Y 이동
SIDE      Z / Y 이동
```

기본값은 스냅 ON입니다. 드래그 중 `Ctrl`을 누르면 일시적으로 스냅이 반대로
동작합니다.

## 4. 여러 정점 선택하기

빈 공간에서 왼쪽 버튼으로 드래그하면 박스 선택이 됩니다.

```text
Shift + 클릭 / 드래그      선택 추가
Ctrl + 클릭 / 드래그       선택 토글
```

여러 정점을 선택한 뒤 선택된 정점 하나를 드래그하면 선택된 정점들이 함께
움직입니다.

키보드로도 조금씩 움직일 수 있습니다.

```text
방향키 / WASD       화면 기준 이동
PageUp / PageDown   깊이 방향 이동
Shift               10배 이동
Alt                 0.1배 이동
```

## 5. 면 선택과 색 바꾸기

면 위에 마우스를 올리면 면이 밝게 표시됩니다.

```text
왼쪽 클릭       면 선택
팔레트 클릭     선택된 면 색 변경
숫자 0~9        빠른 색 적용
```

색은 RGB 재질이 아니라 0부터 15까지의 팔레트 인덱스로 저장됩니다.

## 6. Extrude

면을 선택하거나 면 위에 마우스를 올린 상태에서:

```text
E
```

선택된 면이 법선 방향으로 1칸 밀려나고, 옆면이 자동으로 생성됩니다.
새로 만들어진 윗면이 다시 선택되므로 `E`를 여러 번 누르면 빠르게 형태를
쌓을 수 있습니다.

## 7. Inset

면을 선택하거나 면 위에 마우스를 올린 상태에서:

```text
I
```

면 안쪽에 작은 면이 만들어지고 둘레 면이 자동 생성됩니다. 그 뒤 `E`를 누르면
홈이나 돌출 구조를 빠르게 만들 수 있습니다.

## 8. 프리미티브 추가

`Tab` 또는 `Shift + A`를 누르면 ADD 메뉴가 열립니다.

```text
VERTEX
PLANE
CUBE
PYRAMID
PRISM
CYLINDER
SPHERE
```

복잡한 설정 창 없이 바로 생성됩니다. Cylinder는 기본 8면, Sphere는 낮은
폴리곤 형태로 생성됩니다.

## 9. 삭제, 복제, 병합

```text
X / Delete      선택 삭제
D               선택 오브젝트 복제
M               정점 2개 이상 선택 시 가운데로 병합
```

정점 2개 이상을 고르고 `M`을 누르면 선택 정점들이 중심점으로 합쳐집니다.
정점 선택이 없을 때 `M`은 렌더 모드를 전환합니다.

## 10. 회전과 크기 조절

```text
R       선택 지오메트리 또는 오브젝트 회전
S       선택 지오메트리 또는 오브젝트 스케일
```

현재 활성 뷰를 기준으로 간단하게 동작합니다. 빠른 형태 잡기에 맞춘 MVP
동작입니다.

## 11. 렌더 모드

`M`을 누르면 렌더 모드가 순환합니다.

```text
WIREFRAME
FLAT
FLAT+WIRE
```

기본 모드는 `FLAT+WIRE`입니다.

## 12. 저장과 불러오기

```text
Ctrl + N            새 파일
Ctrl + O            .pf16 열기
Ctrl + S            저장
Ctrl + Shift + S    다른 이름으로 저장
```

샘플 파일:

```text
samples\sample_cube.pf16
```

## 13. OBJ 가져오기와 내보내기

상단 메뉴에서 사용합니다.

```text
FILE > IMPORT OBJ
FILE > EXPORT OBJ
```

OBJ 가져오기는 `v`, `f`를 읽습니다. OBJ 내보내기는 16색 재질을 담은 `.mtl`
파일을 함께 만듭니다.

## 14. 스크린샷

```text
F12
```

현재 Perspective 뷰를 640x480 BMP 이미지로 저장합니다.

기본 저장 위치:

```text
screenshots\
```

## 15. 첫 모델 만들기 연습

아래 순서대로 해보면 전체 흐름을 빠르게 익힐 수 있습니다.

```text
1. 기본 큐브에서 TOP 뷰에 마우스를 올립니다.
2. SPACE로 TOP 뷰를 확대합니다.
3. 정점 하나를 드래그해서 큐브 모양을 살짝 바꿉니다.
4. SPACE로 4분할 뷰로 돌아옵니다.
5. Perspective 뷰에서 면 하나를 클릭합니다.
6. E를 눌러 Extrude합니다.
7. 아래 팔레트에서 색을 클릭합니다.
8. M을 눌러 렌더 모드를 바꿔봅니다.
9. Ctrl+S로 .pf16 파일을 저장합니다.
10. 프로그램을 닫고 Ctrl+O로 다시 열어봅니다.
```

이 도구의 핵심은 모드를 고르는 것이 아니라, 보고 클릭하고 바로 움직이는
것입니다.
